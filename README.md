# 青銅前線

這個 GitHub Pages 網址原本是 EasyChess 西洋棋。現在改放原創單線戰爭 **青銅前線**。

線上：https://ryantsai0119.github.io/EasyChess0119/

玩法接近 Ancient Wars／Age of War：金幣招兵、單位自己上路、拆掉對面營壘。名稱、單位、關卡與畫面都是新做的，不是商業遊戲的複製。

## 操作

- 點單位出兵，或鍵盤 `1`–`9`
- `A` 升年代 · `T` 升砲塔 · `H` 戰號 · `V` 火箭 · 空白鍵暫停
- 進度存在這台瀏覽器（`localStorage` 鍵名 `bronze-front-v1`）

## 本機

用瀏覽器開 `index.html`，或：

```bash
python -m http.server 8765
```

來源在 EasyLinkERP 的 `web/bronze-front/`。
