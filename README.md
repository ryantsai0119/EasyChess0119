# 青銅前線

瀏覽器裡就能打的原創單線戰爭。玩法接近大家常講的 Ancient Wars／Age of War：金幣招兵、單位自己上路對打、毀掉對面營壘。畫面是銅暮剪影：同一套畫筆畫標題、戰場、營壘與指揮列圖示。

這不是任何商業遊戲的複製。名稱、單位、關卡與畫面都是新做的。

## 怎麼開

用瀏覽器直接開 `index.html`，或在這個資料夾起一個靜態伺服器：

```bash
python -m http.server 8765
```

然後打開 `http://localhost:8765/`。

## 操作

- 標題畫面按「開戰」直接進下一場，或從戰役選關
- 點底部格子出兵，或鍵盤 `1`–`9`
- `A` 升年代 · `T` 升砲塔 · `H` 戰號 · `V` 火箭
- 空白鍵或 `Esc` 暫停；聲音與撤出在暫停選單裡
- 進度存在這台瀏覽器的 `localStorage`（鍵名 `bronze-front-v1`）

## 聲音

- 第一次點畫面後才開音訊（瀏覽器限制）
- 標題／戰役有低鳴環境；開戰後加遠鼓
- 出兵、砍擊、射箭、戰號、火箭、勝負各有對應音效
- 暫停選單可關聲音

## 戰役

八場，難度遞增。第一場只會遇到銅器敵兵，後面才會升鐵器、鑄鋼。
